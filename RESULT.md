## Delivered mechanisms

`scripts/run.py` now creates a fresh whitelisted workspace and isolated session, runs bounded Codex work slices, independently checks each stopped candidate, and returns actual errors and open global obligations to the same conversation. Cumulative time, rounds, tool versions, session identity, attempted approaches and redesign counts survive resume. Consecutive unchanged independent gaps trigger a bounded redesign, not an empty restart. Local verified counts and agent completion claims do not establish progress toward final acceptance. Interrupted attempts retain their history and reserved budget; process-group cleanup and an external lock prevent overlapping controller writes.

`scripts/inputs.py` centralizes the explicit input list. Preparation-side `runs/.controller/<name>/` holds the independent standards and controller state outside the candidate's writable workspace. New copies exclude old source answers, proof files, prompts, logs, sessions, patches and compiled protocol outputs. Resume requires the new-system origin and matching input/tool versions; it cannot adopt an old session as a fresh experiment. Preview creates nothing and calls no model. There are no approval files or per-round human approval checkpoints.

`scripts/check.py` records actual commands, tool environment, candidate version, raw diagnostics and per-obligation results. It checks all retained test families at seeds 1–5 on one source-only snapshot, verifies required test names rather than accepting an empty/partial run, and detects changes to original tests, requirements, helpers, Cargo configuration or checked source. Both `safety` and `final` perform complete acceptance; `top NAME` supplies partial proof feedback without skipping imported function bodies. Complete acceptance reruns the real aggregate caller and cannot be assembled from earlier PASS records.
